# 模型说明

本文描述《微疫世界》的世界模型、守恒保证、时间与随机数体系、六种异常的机制差异、人类响应AI与自动演化决策的规则。

## 1. 总体结构

- **聚合模型**：不逐人模拟。每个区域维护 6 个浮点状态量：`S`（易感）、`E`（潜伏）、`I`（活动感染）、`R`（康复/免疫）、`D`（死亡）、`C`（晶化，仅晶化异常使用，其余异常恒为0）。
- **80个游戏区域**：属性为玩法数据——人口、气候标签（热/温/寒/旱）、城市化、富裕度、医疗承载(1-5)、研究承载(1-5)、沿海、枢纽级。世界总人口约47.8亿（**玩法虚构数据**）。
- **稀疏连接**（约186条，由规则从区域属性确定性生成）：
  - 陆路约82条：人工编写的接壤关系（游戏抽象）；
  - 海路约50条：沿海区域 → 最近的沿海枢纽（距离衰减）；
  - 空路约70条：10个世界枢纽两两互联 + 一级枢纽挂靠 + 富裕区挂靠。

## 2. 时间与频率

- 1 tick = 1 游戏日。基础速度 1× = **1 tick/秒**（2× = 2Hz），满足"仿真基础更新约1—2Hz"。
- 60 FPS 是**渲染频率**：地图动画（脉动、涟漪、航线图标、颜色过渡）每帧重绘，但世界数据只在 tick 时更新为"目标值"，帧间只做插值——**绝不每帧重算世界**。
- **速率与时间步显式关联**：加速不改变 dt（恒为1天/步），而是每帧多跑固定步数。帧间债务有上限（`MAX_DEBT_TICKS=90`），长时间卡顿只会"变慢"，不会爆发补算，也不会数值发散。
- **帧率无关性**：给定同样的速度操作序列，tick 序列与批次无关（测试`补算批次大小不影响结局`验证了1/17/变步长三种批次产生完全一致的状态哈希）。

## 3. 状态转移（有界流）

每 tick 对每个区域（固定索引序）执行：

```
新暴露  newE = β_eff · I · S / L + ε·C·S/L (晶尘) + S·压力导入
   约束: 0 ≤ newE ≤ 0.5·S
潜伏发病 toI = min(σ·E, E)
康复    toR = min(γ_eff·I, I)
死亡    toD = min(μ_eff·I, I - toR)
晶化    toC = min(χ·I, I - toR - toD)        (仅晶化)
免疫消退 toS = min(ω·R, R)                   (R→S，支持"反复"与长期共存)
晶化逆转 rev = min(0.05·C, C)               (解药部署后 C→R)
```

其中：
- `β_eff = β · 气候亲和[气候] · 季节项 · (1+城市敏感度·城市化) · (1-卫生运动) · 事件修正 · (爆发乘数) · 燃尽项 · 封锁后抑制`
- `γ_eff` 随医疗承载、援助、解药部署提升；`μ_eff` 随医疗与援助下降（上限0.85的削减）。
- **燃尽项**（焰袭）：易感占比低于50%时，β 按 `(1 - burn·(1-sShare/0.5)·1.2)` 衰减——烧完燃料自然熄灭。
- **爆发**（共鸣）：`I/L>1.5%` 时每日以 `burstP·(0.5+城市化)` 概率触发，当日 β×爆发放大倍数，计入统计与地图涟漪。
- **唤醒波**（休眠）：每日以 `reappear` 概率使该区域当日 σ×2.2，形成复燃波。

### 压力导入（跨区传播）

不迁移人口。每条连接向对端注入"出行暴露压"：

```
pIn[对端] += φ · 封锁乘数[通道] · 事件出行乘数 · 通道亲和 · (I源 + 0.35·E源) / L源
晶化附加：晶尘经空路(×1)与陆路(×0.3)按 C源/L源·ε·0.6 注入
```

这等价于通勤往返净值为零的聚合近似：**人口不随交通迁移**，因此区域人口只因死亡而下降，彻底杜绝"靠复制人口实现跨区输入"。

### 守恒保证

1. 所有转移都是 `min(rate×src, src上限)` 形式的**有界流**：减去多少，加到哪，不存在凭空增减；
2. 人口恒等式 `S+E+I+R+D+C ≡ 初始人口`（初始感染源从 S 扣减转 E）；
3. D 单调不减（不重复死亡）、C 只在解药部署后下降（逆转为 R）；
4. 浮点漂移在 1e-9 相对量级（测试容差 1e-9·pop），3000日守恒测试通过。

## 4. 随机数体系

- 三条独立的 **mulberry32** 流：`sim`（区域 dynamics/爆发/唤醒）、`ev`（事件）、`evo`（演化抖动），全部随存档保存（各一个 uint32 状态）。
- **仿真内禁止** `Math.random / Date.now / 超越函数`：仅用 `+ - × ÷ min max clamp` 与 `sqrt`（IEEE 754 规定 sqrt 必须正确舍入，跨引擎确定）。测试用"替换 Math.random 即抛错"的方式验证了600日纯度。
- 视觉随机数独立成流（不进存档），修改画质不影响模拟。

## 6. 人类响应AI（状态驱动，非定时脚本）

- **觉察度**：区域 `aw = 0.9·aw + 0.1·min(1, 感染可见度·12 + 事件)`；全局觉察 = 0.55·人口加权 + 0.45·感染区加权，下限 = 最警觉区域×0.45（"新闻传开"）。
- **研究**：日研究点 `rp = Σ区域产出 × 资金曲线 × 0.055 × 场景系数`；资金曲线 `0.4 + 2.6·awG·(2-awG) + 1.2·研究进度`（研究动能：进度不会因疫情退潮而一夜归零）。62%进解药（解药总量 30000×抗性），26%进援助池。部署后：β×0.35、γ+75%、医疗+0.35、晶化逆转开启。
- **援助**：每3天向"严重度×医疗缺口×未饱和度"最高的区域投放，提升医疗、降低死亡；按日衰减。
- **卫生运动**：目标强度 = 觉察 × (0.18 + 0.5×研究进度) × 富裕系数——**早期只有基本防护**，随研究深入而强化（避免萌芽期被掐死）。
- **交通封锁**（迟滞）：需全局觉察>0.08；阈值 `0.016·(1+18μ)/[(0.55+0.9·awG)·场景aggr]`，空/海/陆阈值 1×/1.7×/2.6×，重开阈值为一半。封锁是**唯一**写入连接模型的地方，新闻由同一代码路径发出——保证"新闻说关，模型必关"。

## 7. 自动演化决策（本地规则评分，无LLM）

- **适应点收入**：`0.03 + √(感染百万人) × 0.045 /日`（√ 为IEEE正确舍入运算）。
- **冷却**：购买后3日。
- **候选合法性**：未拥有 + 前置满足 + 资源足够（测试全程断言适应点≥0、前置在购买时已满足、冷却间隔≥3日）。
- **评分**：`Σ线索分 / (1 + 成本×0.04) + 解锁子节点数×5 + 确定性抖动`。线索分（按当前世界状态）：广谱传播面30、气候未渗透26、城市24、援助/封锁抗性随研究进度36、隐匿随(1-觉察)22、侵蚀24、爆发12、晶尘储库30等。
- **解释**：每次购买记录主因（如"寒带人口尚未渗透"）与备选对比，写入演化历史与结局复盘。
- **保底**：250日无购买时强制采纳最高分候选，防止主线链被低分卡死。

## 8. 事件系统（43条）

每条事件 = 触发条件（世界状态谓词）+ 每日概率×频率设置 + 冷却 + 后果。后果通过三类通道写入模型：全局修正（β/研究/警觉）、通道出行乘数、区域修正（β/警觉/医疗/卫生/产出）。异常互动类事件（晶尘风暴、雾潮涌动、潜伏唤醒、余烬复燃等）以异常实际状态为前提。所有修正每 tick 聚合一次，随存档保存到期时间。

## 9. 结局（6种，带持续天数门槛）

| 结局 | 条件（持续天数） |
|---|---|
| 扑灭纪元 | 解药部署 且 I<60 且 E<400 且 C<800（25日） |
| 静默方舟 | 活人<62% 或 死亡>21%（30日） |
| 晶界时代 | 晶化占比>27%（30日） |
| 潮汐平衡 | 未部署解药 且 感染占比稳定于 0.05%–2% 且 警觉>35%（120日） |
| 灰烬退潮 | 未部署解药 且 感染<2000 且 晶化<2000（90日）——异常自熄 |
| 长夜胶着 | 第4600天仍无定论 |

实测分布（9组场景×异常×种子）：eradicated / stalemate / collapse / crystal 四类出现，平均 2739 天 ≈ **46分钟（1×）**，落在45–120分钟设计窗口；不同种子与场景走向不同（无必然结局）。

## 10. 存档与离线进度

- **存档内容**：完整状态——模拟时间、三条随机数流状态、区域六联组、连接封锁态、研究/援助/事件修正/冷却、环形历史（1500样本）、新闻（400条）、演化日志（200条，含决策理由）、结局持续计数器、版本号。双槽轮换 + FNV-1a 校验和；坏槽自动回退，坏文件导入被拒绝且不污染现有存档。
- **离线补算**：锚点先行（先写新锚点再补算——中断只会"少推"，**不会把同一段时间推进两次**）；时钟回拨/重复恢复（Δ≤0）不推进；暂停不累计；默认上限8小时，上限内逐日全量分批补算（每帧≤600日，约0.06ms/日，不卡帧）；超出部分按周"跳过并记录"，界面明确标注"快速推进（近似处理，与实时运行不完全等价）"。
- **时钟与休眠**：可见性隐藏即停绘+存档；恢复时按 `catchupCompute`（纯函数）计算补算量；RAF 饥饿看门狗兜底（窗口被遮挡/合成器节流时由定时器低速驱动，带8ms帧锁防止双重推进）。

## 11. 性能（Node 24 实测）

- 单 tick 平均 **0.035–0.038 ms**（0.03核的3.5%——常态计算预算远低于1逻辑核）；
- Node 堆 ≈ 27–33 MiB（核心+世界状态）；
- 8小时离线全量补算 ≈ 43200 tick ≈ 1.6秒CPU，分批后无卡顿。
