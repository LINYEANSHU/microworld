# 未完成清单（诚实清单）

## 已知偏差

1. **内存预算未达标**：浏览器方案的游戏实例进程树私有提交 ≈ 740–780 MiB（目标 ≤512 MiB）。超出部分为 Chromium 多进程运行时基线；游戏自身 <40 MiB。已达成的替代保证：CPU 常态 ≈ 3.5% 单核（不干扰后台训练的目标由此达成）。**达标路径**（择一，未实施）：
   - WebView2 单宿主窗口（预计 <300 MiB，需 WebView2 运行时 + 少量 C#/C++ 壳）；
   - 仍用浏览器但接受现状（当前交付形态）。
2. **60 FPS 为结构保证而非自动化实测读数**：开发用自动化浏览器面板节流 RAF，无法在无人值守环境读出 FPS。已在渲染器内做"目标值+插值、对象数有上限"的结构性保证；请在真实桌面窗口肉眼验收（菜单→性能统计可看 FPS）。

## 功能延期（架构已留口）

3. **本地场景包/创意工坊式扩展**：**已实现（2026-11）**——`js/core/workshop.js` 提供 JSON 场景包的校验（未知参数/越界数值/非法 id 拒绝）、注册（与内置场景同路径合成）、跨会话持久化与导入/导出；菜单「导入场景包」即用。仍不做编辑器 UI 与上传分享链路。
4. **音效**：无任何音频资源；如需环境音/事件提示音，需引入最小 WebAudio 合成器（默认静音原则不变）。
5. **手动干预的深度**：**部分已实现（2026-11）**——"手动指示人类响应"中的**优先援助**已落地（区域详情「设为优先援助」，援助评分×2.5、不突破容量上限，存档保留）；手动演化购买此前已有。更深度的定向干预（如指定封锁策略）仍未做。
6. **多异常共存局面**：单局只有一种异常类型（与参考作的单位疾病一致）；"两种异常交互"的世界留待后续。

## 质量/测试待补

7. **真实桌面长时挂机观测**（45–120分钟多轮、睡眠/唤醒、多显示器拔插、DPI缩放变化、Edge/Chrome 多版本矩阵）——已由单测覆盖逻辑面，真机矩阵未跑。
8. **触屏/高DPI细节**：canvas 已按 devicePixelRatio ≤2 处理，触屏双指缩放未实现（滚轮/拖拽可用）。
9. **平衡性的大规模扫描**：**工具已实现（2026-11）**——`node tools/sweep.js`（可 `--scen/--anom/--seeds/--days`）输出结局分布与时长/死亡百分位（P10/P50/P90）；`runBatch` 同时被 run-tests 用例覆盖。按百分位"严格控制"的调参决策仍需人工进行。
10. **i18n**：界面仅中文；文案集中在 data 与 ui 层，翻译可后补。
