# 资源来源

本作遵循"离线、本地打包、无版权风险"原则。全部资源清单如下：

## 1. 地图轮廓数据

- **来源**：[world-atlas](https://github.com/topojson/world-atlas) v2.0.2 的 `land-110m.json`（TopoJSON）。
- **原始数据**：Natural Earth（[naturalearthdata.com](https://www.naturalearthdata.com/)）110m 陆地轮廓 —— **公有领域（Public Domain）**，无署名要求。
- **world-atlas 包许可**：MIT。
- **获取方式**：开发期通过 `curl` 一次性下载到 `tools/land-110m.json`（仅生成工具使用）；由 `tools/gen-land.js` 解码弧段、Douglas-Peucker 简化（容差0.55°）、过滤 <1.1 平方度小岛后，输出为 `js/data/land.js`（17.4KB，78个多边形、1359个顶点）。
- **加工说明**：游戏内以等距圆柱投影、深色风格化重绘；不使用原始配色与任何官方渲染样式。跨±180°的环在绘制时断开。
- **定位**：仅作背景轮廓，区域划分为本作虚构的80个"游戏区域"，不代表真实行政区划主张。

## 2. 字体

- 使用操作系统自带字体栈：`"Segoe UI", "Microsoft YaHei", system-ui`。**不打包、不分发任何字体文件**。

## 3. 图标与美术

- 全部为代码绘制（Canvas 2D / CSS / Unicode 符号）：地图、区域脉动、涟漪、航线图标、晶化漂白、雾潮色调等均由 `js/ui/render.js` 程序化生成，无图片资源、无第三方图标库。

## 4. 声音

- 默认无声音（不打包任何音频资源）。设置中的"静音"开关为预留位。

## 5. 第三方代码

- **无任何运行时第三方依赖**。所有 JS 均为本作手写（mulberry32 随机数、FNV-1a 哈希、Douglas-Peucker 简化等均为公开算法的独立实现）。
- 测试与构建使用 Node.js 内置模块（http/fs/path），未安装 npm 包。
